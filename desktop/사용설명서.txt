========================================================
 SHP 좌표변환·병합·분할 도구 — 사용설명서 (v1.3.0)
========================================================

■ 이 프로그램은?
  SHP/GPKG 파일의 좌표계를 바꾸고, 합치고, 나누고, 코드표를 붙이는 도구입니다.
  설치가 필요 없습니다. SHP도구.exe 를 더블클릭하면 바로 실행됩니다.

--------------------------------------------------------
■ 처음 한 번만: QGIS가 깔려 있어야 합니다
--------------------------------------------------------
  좌표변환 같은 실제 작업은 QGIS에 같이 들어있는 'GDAL'이 처리합니다.

  · 이미 QGIS를 쓰고 있다면  → 아무것도 안 해도 됩니다. 앱이 알아서 찾습니다.
    앱 오른쪽 위에 "✅ GDAL 연결됨" 이 보이면 준비 끝입니다.

  · QGIS가 없다면 → 앱을 켜면 뜨는 안내 창에서 [QGIS 내려받기] 를 눌러
    설치하세요(설치 중 계속 '다음'만 눌러도 됩니다). 설치 후 앱에서
    [GDAL 다시 찾기] 를 누르면 연결됩니다.

  · "❌ GDAL을 찾지 못했습니다" 가 계속 뜬다면
    → 'GDAL/QGIS bin' 칸에 아래 같은 폴더를 넣고 [GDAL 다시 찾기] → [설정 저장]
         C:\Program Files\QGIS 3.30.3\bin
         C:\OSGeo4W\bin

  ※ exe 는 바탕화면이나 내 문서처럼 '쓰기 되는 곳'에 두세요.
     (설정이 config.txt 에 저장됩니다. 쓰기 금지 폴더면 자동으로
      C:\Users\사용자\AppData\Roaming\SHP도구\ 에 저장됩니다.)

--------------------------------------------------------
■ 쓰는 순서
--------------------------------------------------------
  1) 파일 넣기
     · 앱 위쪽 파란 상자에 파일을 그냥 끌어다 놓으세요(드래그앤드롭).
       코드표 CSV도 끌어다 놓을 수 있습니다(v1.3.0부터). 큰 상자에 놓아도 되고,
       [4. 코드 결합] 탭의 '코드표 CSV를 여기로 끌어다 놓으세요' 칸에 놓아도 됩니다.
       .shp / .gpkg / .zip 파일도 되고, 폴더째 끌어놓아도 됩니다.
       (zip 은 자동으로 풀리고, 폴더는 하위 폴더까지 다 뒤져서 찾습니다)
     · 버튼으로 넣어도 됩니다: [파일 선택] / [폴더 선택]

  2) 공통 설정 확인
     · 입력 DBF 인코딩: 국내 공공데이터는 보통 CP949 입니다.
       한글이 깨져 보이면 → [5. 속성·인코딩 확인] 탭에서
       '깨짐 의심 점수'가 가장 낮은 인코딩으로 바꾸세요.
     · 결과 저장 폴더: 기본은 바탕화면\SHP도구_결과 입니다.

  3) 탭을 골라 실행
     결과는 '작업명_날짜시각' 폴더로 매번 새로 생기므로
     이전 결과를 덮어쓰지 않습니다. 끝나면 폴더를 열지 물어봅니다.

--------------------------------------------------------
■ 탭별 기능
--------------------------------------------------------
  [1. 좌표계 변환]
    목표 좌표계(예: EPSG:5186 중부원점)로 일괄 변환합니다.
    · '안전 변환 모드'(기본 켜짐) 권장 — 도형을 복구한 뒤 변환하고,
      변환 전/후 도형 개수를 비교해 사라진 게 있으면 알려줍니다.
    · 도형이 사라지거나 엉뚱한 곳에 찍히면
      → '원본 EPSG 강제 지정'에 실제 좌표계(예: 5174)를 넣고 다시 실행.
    · 면적(area_m2) 컬럼도 같이 넣을 수 있습니다.
      ※ 면적은 5186 같은 '미터 좌표계'에서만 정확합니다(4326은 안 됨).

  [2. 레이어 병합] — 세 가지 중 선택
    · 컬럼값 기준 병합(도형도 합침)
        같은 값끼리 도형을 하나로 합칩니다(예: 용도지역별로 하나씩).
    · 속성만 합치기(도형·개수 유지)
        도형은 하나도 안 건드리고, 그룹별 면적합계 같은 값만
        새 컬럼으로 각 도형에 붙입니다.
    · 여러 레이어 이어붙이기
        여러 SHP를 하나로 이어붙입니다(컬럼이 달라도 됩니다).

  [3. 레이어 분할]
    기준 컬럼을 고르고 [고유값 불러오기] → 원하는 값만 남기고 실행하면
    값마다 파일이 하나씩 만들어집니다. 비워두면 전체 값으로 분할합니다.

  [4. 코드 결합]
    속성의 코드(예: mnum 21번째부터 6자리)를 뽑아 코드표 CSV를 붙입니다.
    실행 전에 [코드 미리보기]와 [매칭률 확인]으로 맞는지 꼭 확인하세요.
    ※ 한글 컬럼이 많으면 저장 형식을 GPKG로 하세요
      (SHP은 컬럼명이 10바이트로 잘립니다 = 한글 5자)

  [5. 속성·인코딩 확인]
    속성 표를 미리 보고, 어떤 인코딩이 안 깨지는지 점수로 비교합니다.

--------------------------------------------------------
■ 알아두면 좋은 것
--------------------------------------------------------
  · SHP 저장이 실패하면 자동으로 GPKG로 저장합니다(결과가 안 나오는 일 방지).
    GPKG는 QGIS에서 SHP과 똑같이 열립니다.
  · 작업 중에도 창은 안 멈춥니다. 아래 진행바와 로그를 보세요.
  · 문제가 생기면 아래 [로그 저장] 을 눌러 나온 파일을 담당자에게 보내주세요.
    실행된 명령이 그대로 들어있어 원인 파악이 빠릅니다.

  · 앱이 아예 안 켜지거나 GDAL을 계속 못 찾으면 '자가진단'을 돌려주세요.
      1) exe가 있는 폴더 주소창에 cmd 입력 후 엔터
      2) 아래 명령 입력
           SHP도구.exe --selftest
      3) 같은 폴더에 생긴 '진단결과.txt' 를 담당자에게 전달
    (창은 안 뜨고 파일만 만들어집니다)

■ 자주 있는 문제
--------------------------------------------------------
  Q. 한글이 ???? 나 깨진 글자로 보여요
     → 입력 DBF 인코딩을 CP949 ↔ UTF-8 로 바꿔 보세요.
        [5. 속성·인코딩 확인] 탭의 점수가 낮은 쪽이 정답입니다.

  Q. 변환했더니 도형이 몇 개 사라졌어요
     → '원본 EPSG 강제 지정'에 원래 좌표계 번호를 넣고 다시 실행하세요.
        (.prj 파일이 없거나 잘못된 경우가 대부분입니다)

  Q. 면적이 이상해요(너무 작거나 0.000x)
     → 목표 좌표계가 4326(위경도)이면 그렇습니다. 5186으로 바꾸세요.

  Q. 결과 파일이 안 보여요
     → 완료 창에서 [예]를 누르거나, 앱의 [결과 폴더 열기] 를 누르세요.
