# SHP 좌표변환·병합·분할 도구 — 데스크톱 (Windows)

웹 버전(https://gis-shp-tool.streamlit.app)과 **똑같은 기능·똑같은 GDAL 엔진**을 쓰는 내 PC 전용 앱입니다.
업로드/다운로드가 없어서 **큰 SHP도 그냥 열리고**, 결과는 내가 정한 폴더에 바로 저장됩니다.

| |웹 버전|데스크톱(이 폴더)|
|---|---|---|
|파일 넣기|업로드(용량 제한·느림)|내 폴더에서 바로 읽기|
|결과 받기|zip 다운로드|지정 폴더에 바로 저장|
|대용량|연결 끊김/절전 이슈|제한 없음(내 PC 성능만큼)|
|GDAL|클라우드의 gdal-bin|내 PC의 QGIS|

## 준비물 — QGIS 하나면 끝
좌표변환·병합·분할은 GDAL(`ogr2ogr.exe`)이 합니다. **QGIS를 설치하면 GDAL이 같이 깔립니다.**
- 이미 QGIS가 있으면 → 앱이 `C:\Program Files\QGIS 3.xx\bin` 을 **자동으로 찾습니다**. 할 일 없음.
- 못 찾으면 앱 오른쪽 위 **GDAL/QGIS bin** 칸에 그 `bin` 폴더를 넣고 **[GDAL 다시 찾기]** → **[설정 저장]**.
- QGIS가 없다면: [qgis.org](https://qgis.org) 에서 설치하거나, 명령창에서 `winget install OSGeo.GDAL`.

앱 오른쪽 위에 **✅ GDAL 연결됨** 이 뜨면 준비 완료입니다.

## 실행
```bat
pip install tkinterdnd2      # 드래그앤드롭용(선택 — 없으면 버튼으로만 파일 넣기)
python app.py
```
그 외 파이썬 패키지는 필요 없습니다(표준 tkinter 사용).

## 사원 배포 (exe 만들기)
```bat
build.bat        (더블클릭)
```
만들어지는 것:

| 결과물 | 설명 |
|---|---|
| `dist\SHP도구.exe` | 프로그램 본체(약 13MB, 설치 불필요) |
| `dist\SHP도구_배포_v1.0.0.zip` | **사원에게 줄 파일** — exe + 사용설명서.txt |

- 받는 사람은 **압축 풀고 exe 더블클릭**이면 끝입니다. 준비물은 **QGIS**뿐(아래 참고).
- QGIS가 없으면 앱이 켜질 때 **안내 창**이 떠서 [QGIS 내려받기] 버튼으로 바로 갈 수 있습니다.
- exe 속성에 이름·버전이 표시되고 전용 아이콘이 붙습니다(`make_icon.py`로 생성, `icon.ico`).
- 기존 exe가 **실행 중이면 잠겨서 빌드 실패**합니다. 창을 닫고 다시 실행하세요.
- 설정(`config.txt`)은 exe와 같은 폴더에 저장되고, 그 폴더가 **쓰기 금지(Program Files 등)면
  자동으로 `%APPDATA%\SHP도구\`** 로 대피합니다. 어디에 뒀는지는 앱 로그 첫 줄에 찍힙니다.

> 이 앱은 **인터넷·API를 전혀 쓰지 않습니다**(VWorld 등 인증키 불필요). 파일 처리는 전부 사내 PC 안에서 끝납니다.
> 인증키가 필요한 건 형제 앱인 주소PNU변환기(gis-address-tool)이고, 그건 앱 안에서 개인별 키를 입력·저장합니다.

## 쓰는 순서
1. **① 파일 불러오기** — 파란 상자에 **끌어다 놓으면(드래그앤드롭)** 바로 읽습니다.
   `.shp`/`.gpkg`/`.zip` 파일도 되고 **폴더째** 끌어놓아도 됩니다(여러 개 한 번에 OK).
   버튼([파일 선택]/[폴더 선택])으로 넣어도 같습니다. 하위 폴더까지 훑어 레이어를 모두 찾습니다(zip은 자동으로 풀림).
2. **② 공통 설정** — 입력 DBF 인코딩(국내 공공데이터는 보통 `CP949`), SHP 출력 인코딩, 결과 저장 폴더.
   - 한글이 깨져 보이면 **5번 탭 [속성·인코딩 확인]** 에서 '깨짐 의심 점수'가 가장 낮은 인코딩으로 바꾸세요.
3. 탭에서 작업 선택 → 실행. 결과 폴더는 **작업명_날짜시각** 으로 매번 새로 생겨 이전 결과를 덮어쓰지 않습니다.

## 탭별 기능 (웹과 동일)

### 1. 좌표계 변환
- 목표 좌표계 선택(5186 중부원점 등) 또는 EPSG 직접 입력.
- **안전 변환 모드(권장·기본 켜짐)**: ① 원본 좌표계 확정 + 도형 복구(재투영 없이) → ② 재투영 + 도형 복구.
  단계별 피처 수를 로그에 찍어 **어디서 몇 개가 사라졌는지** 알려줍니다.
- `.prj`가 없거나 틀리면 **원본 EPSG 강제 지정**(예: `5174`)에 실제 좌표계를 넣으세요. 피처 손실의 가장 흔한 원인입니다.
- **면적 컬럼(area_m2)** 추가 옵션 — 5186 같은 **미터 좌표계**에서만 ㎡가 정확합니다(4326은 제곱도).

### 2. 레이어 병합 (3가지)
- **컬럼값 기준 병합(도형도 합침)** — 같은 값끼리 하나의 멀티파트 도형으로. 인접 도형의 *공유 내부 경계*만 지우고 바깥 윤곽선은 유지합니다. 경계선 깨짐 방지를 위해 병합 전 도형 복구를 항상 수행합니다.
- **속성만 합치기(도형·개수 유지)** — 폴리곤은 하나도 안 바뀌고, 그룹별 집계값(면적 합계 등)만 새 컬럼으로 붙습니다. 그룹 면적은 `ST_Union`으로 계산해 **겹친 부분을 두 번 세지 않습니다**.
- **여러 레이어 이어붙이기** — 컬럼이 서로 달라도 `-addfields`로 합쳐집니다.
- 집계표에서 컬럼을 고르고 방식(합계/평균/최대/최소/개수/텍스트 이어붙이기)을 정한 뒤 **[선택 컬럼에 적용]**.

### 3. 레이어 분할
- 기준 컬럼 → **[고유값 불러오기]** → 원하는 값만 남기고 실행. 값을 비우면 전체 고유값으로 분할합니다.
- **포함 조건(%값%)** 체크 시 부분 일치로 분할합니다.

### 4. 코드 결합
- 속성의 `mnum` 같은 컬럼에서 `substr(시작, 길이)`로 코드를 뽑아 **코드표 CSV**를 LEFT JOIN.
- **[코드 미리보기]** 로 시작/길이가 맞는지, **[매칭률 확인]** 으로 코드표와 얼마나 맞는지 먼저 확인하세요.
- 코드표 CSV 인코딩은 자동 추천됩니다(깨짐 점수 최저값).
- SHP은 필드명이 10바이트로 잘립니다(한글 5자) → 한글 컬럼이 많으면 **GPKG 저장 권장**.

### 5. 속성·인코딩 확인
- 인코딩 후보별 깨짐 점수 비교 + 속성 앞 30행 미리보기.

## 알아두면 좋은 것
- **SHP 저장이 실패하면 자동으로 GPKG로 대체 저장**합니다(빈손 방지). QGIS에서 똑같이 열립니다.
- 한글이 깨지는 걸 막으려고, 공간 SQL 결과는 항상 UTF-8 GPKG를 거쳐 최종 형식으로 저장합니다.
- 결과 폴더의 `_`로 시작하는 중간 파일은 작업이 끝나면 자동 정리됩니다.
- 처리 로그에는 실제 실행된 `ogr2ogr` 명령이 그대로 남습니다 — 문제가 생기면 **[로그 저장]** 해서 그대로 물어보세요.
- 무거운 작업은 백그라운드로 돌아 창이 멈추지 않습니다(진행 상황은 아래 진행바·상태줄).

## 설정 파일(config.txt)
앱과 같은 폴더(쓰기 금지면 `%APPDATA%\SHP도구\`)에 생기며 **[설정 저장]** 을 누르면 갱신됩니다.
```
GDAL_BIN=C:\Program Files\QGIS 3.30.3\bin
OUT_DIR=C:\Users\나\Desktop\SHP도구_결과
IN_ENC=CP949
OUT_ENC=UTF-8
```
